
# Employee Management REST API

A RESTful Employee Management API built with Java and Spring Boot. The application supports creating, retrieving, updating, and deleting employee records, with PostgreSQL for persistent storage and Swagger UI for interactive API documentation.

## Features

- Create, retrieve, update, and delete employees (CRUD)
- RESTful API endpoints
- PostgreSQL database integration
- Request validation
- Centralized exception handling
- Interactive API documentation with Swagger UI
- Automated tests

## Tech Stack

- **Language:** Java
- **Framework:** Spring Boot
- **Database:** PostgreSQL
- **Persistence:** Spring Data JPA, Hibernate
- **Build Tool:** Maven
- **API Documentation:** OpenAPI / Swagger UI
- **Testing:** JUnit, Spring Boot Test

## Prerequisites

Install the following before running the project:

- Java (compatible with the project's `pom.xml`)
- Maven
- PostgreSQL
- Git

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/rahul14thor/employee-management-api.git
cd employee-management-api
```

### 2. Create the PostgreSQL database

Connect to PostgreSQL and run:

```sql
CREATE DATABASE employee_db;
```

### 3. Configure database credentials

Set the connection details through environment variables. Do not commit passwords to Git.

PowerShell:

```powershell
$env:DB_URL = "jdbc:postgresql://localhost:5432/employee_db"
$env:DB_USERNAME = "postgres"
$secure = Read-Host "Enter PostgreSQL password" -AsSecureString
$env:DB_PASSWORD = [System.Net.NetworkCredential]::new("", $secure).Password
```

### 4. Build the project

```bash
mvn clean package
```

### 5. Run with PostgreSQL

```bash
mvn spring-boot:run "-Dspring-boot.run.profiles=postgres"
```

Wait until Spring Boot reports that the application has started.

## API Endpoints

Base URL: `http://localhost:8080`

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/employees` | Retrieve all employees |
| GET | `/api/employees/{id}` | Retrieve an employee by ID |
| POST | `/api/employees` | Create an employee |
| PUT | `/api/employees/{id}` | Update an employee |
| DELETE | `/api/employees/{id}` | Delete an employee |

## Swagger UI

After starting the application, open:

http://localhost:8080/swagger-ui/index.html

Use Swagger UI to explore endpoints and send API requests from your browser.

## Example Request

### Create an employee

`POST /api/employees`

```json
{
  "firstName": "Rahul",
  "lastName": "Test",
  "email": "rahul.test@example.com",
  "department": "Engineering",
  "jobTitle": "Software Engineer"
}
```

The employee ID is generated by the application/database.
